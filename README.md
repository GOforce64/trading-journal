# Trading Journal

A local-first options trading journal for two strategies: short-dated scalps near the
market open, and earnings IV-crush iron flies.

Your trading data never enters this repository. It lives in your own data directory
(see [the design spec](docs/superpowers/specs/2026-09-22-trading-journal-design.md)).

Quickstart instructions land with the server in Task 8 of
[the Phase 1a plan](docs/superpowers/plans/2026-09-22-phase-1a-foundation-and-iron-fly-journal.md).
